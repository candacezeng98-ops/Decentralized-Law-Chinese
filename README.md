# Decentralized-Law-Chinese（去中心化法律 · 中文版）

欢迎来到 **《Decentralized Law》（去中心化法律）** 的开源中文译本。

**开始阅读：** [译者说明与目录](00-译者说明与目录.md)

## 项目愿景

曾几何时，区块链技术承诺要重构世界的治理。带来全新的金融体系、全新形式的公司企业，乃至全新的国家。然而，这一切并未如愿发生。

为什么？因为统治世界的终究是法律，而非账本上的数字。如果无法在现实世界中影响和触及法律，这个行业便永远无法释放其全部潜力。

本项目通过系统性的翻译与整理，将去中心化法律的前沿思想引入中文社区，探讨区块链如何与法律融合，并为二十一世纪的去中心化经济构建坚实的法理基础。

## 关于原著

本译本基于 **Wesley Thysse** 所著的《Decentralized Law: The Power of Blockchain to Transform the Broken Legal System》（第一版，2025 年 5 月）。

- **原作者：** [Wesley Thysse](https://github.com/vattelum)
- **原著在线阅读/下载：** [https://decentralizedlegalsystem.com/law/](https://decentralizedlegalsystem.com/law/)
- **译者：** silentw0lf

本书不仅是对去中心化技术的分析，更是一场关于法律本质的探索。全书重审法律的四大源头：自然法、市民法、国际法与私法，并深入讨论智能合约、代币化、DeFi、DAO 以及去中心化司法等核心议题。

本中文译本依据原作者授权翻译，仅供非商业阅读与研究使用。原书数字 PDF 版采用 Creative Commons BY-NC-ND 4.0 许可；完整译本之制作与存放已获作者书面授权。
