# 创业构想清单

对那些受使去中心化法律成为现实所启发的人，以下创业构想清单或许有所助益。

- **智能合约块：** 成为广为使用的法律模板的受尊敬起草者。
- **共识管辖：** 把这一技术应用于任何既有 DAO 技术，以大幅扩展其用例。
- **缔约元宇宙：** 为商务会议创制一个元宇宙，其中一切达成一致之事都被记录并存储为有约束力的协议。
- **共识国家：** 帮助在法律上尚无牙齿的网络国家获得法律承认。
- **去中心化自治协会：** 转化 DAO 工具，向世界各地的每一家公司或机构提供基于区块链的投票与标准设定。
- **去中心化法律：** 成为你所在行业的首席立法者，并设定未来的标准。对任何基金会、非政府组织、DAO、公司或有抱负的个人开放。
- **Gitlaw：** 把 Git 应用于立法，通过协调与协作来开展工作。
- **去中心化法律体系：** 建造你自己的私法体系，并邀请世界。
- **市场去中介化：** 亚马逊、Upwork 与 eBay 都便利交易。这项工作的一部分——例如条款与条件的设定——可以由共识管辖来完成，合同可以是智能合约块。颠覆的机会无穷无尽……
- **专门化仲裁庭：** 既有或新的法院可以聚焦于特定项目或技术。
- **执行机构：** 《纽约公约》是既定法律。在实践中，送达代理人可能需要帮助请求人使裁决得到执行。
- **信用合作社：** 以资产为基础的货币体系仍然受益于信贷的提供。传统的部分准备金银行难以在 24/7 的加密经济中运作。现代信用合作社可以作为替代信贷提供者。金融监管使通向完全去中心化的道路变得复杂，但这些机构在区域运作、并为生产性目的提供资金时最为有效。
- **货币法：** 货币体系从基于负债的交易向财产权转让的转变，将需要令人望而生畏的大量法律与合同重拟。
- **教育：** 这一新兴行业要求法律顾问具备专门知识，尤其是对跨境法律问题与技术的理解。这些演进中的法律需求要求法律教育的变革。
- **DAO 参与实体：** 为保护参与者免于因 DAO 参与而产生的责任与过重税负，可以创制专门的法律实体或服务。
- **国际标准：** 必须就公约／条约开展工作，使原生代币被确认为无形财产，正如知识产权由《伯尔尼公约》（Berne Convention）所确认。
